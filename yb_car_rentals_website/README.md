# YB Car Rentals website

A responsive, single-page website for YB Car Rentals (self-drive rentals in Delhi).

## Files
- `index.html` — website content and sections
- `style.css` — responsive layout and styling
- `script.js` — mobile menu, enquiry form and WhatsApp handoff

## Run locally
Open `index.html` in a browser. No build tools are required.

## Before publishing
1. Confirm the correct business name, phone numbers, address and WhatsApp number.
2. Replace the CSS car illustrations with approved real vehicle photos if available.
3. Confirm which cars are currently available and update the fleet list.
4. Verify the wording of the review excerpts and link to the correct Google Business Profile.
5. Add privacy/terms pages if collecting customer data or adding analytics.
6. Deploy the folder to a static host such as Netlify, Vercel, or GitHub Pages.

The enquiry form does not collect or store information on this website. It opens WhatsApp with a prefilled message. Rates are intentionally not invented; customers are asked to confirm current rates and conditions directly.
